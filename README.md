# AeroBMSCE Website Redesign

A responsive, multi-page website redesign for the AeroBMSCE Web Development Recruitment Task.

## Project Overview

The website presents AeroBMSCE, its work, journey, achievements, and partnership opportunities through a modern, aerospace-inspired interface.

### Pages

- **Home:** Introduction, club overview, and areas of work.
- **Journey:** Team highlights, project statistics, and a timeline.
- **Partners:** Partnership opportunities, benefits, and contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages for deployment

## 1. What were the flaws in the original website?

The original website had several usability and presentation issues:

- The layout relied on fixed widths and heights, making it difficult to adapt to different screen sizes.
- The typography and visual hierarchy were inconsistent.
- Some text and visual elements lacked sufficient contrast.
- The layout relied on older techniques that made responsive behaviour harder to maintain.
- Navigation and page presentation needed a more consistent structure.
- Some content and formatting needed clearer presentation.

These issues made the original experience less polished and harder to use on mobile devices.

## 2. What design route did you take, and why?

I chose a modern aerospace-inspired visual direction using a dark navy background, bright orange accents, clear typography, and aircraft imagery.

The design decisions were made to:

- Reflect the aerospace and engineering identity of AeroBMSCE.
- Establish a clear visual hierarchy so visitors can scan important information quickly.
- Use consistent navigation across pages.
- Organize content into readable sections and cards.
- Provide responsive layouts for desktop and mobile screens.
- Make partnership information and contact options easier to discover.

The redesign prioritizes clarity, consistency, accessibility, and ease of navigation while maintaining a strong visual identity.

## 3. What was one problem you faced, and how did you solve it?

One important challenge was making the website usable across different screen sizes without allowing the navigation and content layouts to become crowded.

I addressed this by using CSS media queries, flexible layouts, responsive grids, and a mobile navigation menu. I also checked the page structure and navigation during local testing.

Another content consideration was that the original material listed historical years and statistics without explaining every milestone in detail. I kept milestone descriptions general rather than inventing unsupported historical claims.

## Local Setup

1. Clone your fork of the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or another local static web server.
4. Navigate between the Home, Journey, and Partners pages.

## Deployment

The website is intended to be hosted using GitHub Pages. Enable GitHub Pages in the repository settings and select the branch and folder containing the website files.
